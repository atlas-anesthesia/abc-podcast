One-time setup for auto-syncing subscribable feed

To have new episodes appear in Google Calendar automatically, host the .ics file at a stable URL (free with GitHub Pages):

  1. Create a new public GitHub repo (e.g. abc-podcast-calendar).
  2. Upload abc-podcast.ics to the repo's root.
  3. In repo Settings → Pages, enable Pages from the main branch.
  4. Your file will be at: https://<your-github-username>.github.io/abc-podcast-calendar/abc-podcast.ics
  5. In Google Calendar, click + next to "Other calendars" → From URL → paste the URL above.

Each time you update the schedule: re-download the .ics and replace it in the GitHub repo. Google Calendar polls roughly every 24h. (For instant updates on your own calendar, just use the per-event "Add to Google Calendar" link on each scheduled call.)
