Optional: auto-syncing Google Calendar feed

Your app is already at atlas-anesthesia.github.io/abc-podcast/. You can put the .ics file in that same repo so Google Calendar can subscribe to it.

  1. Click Download abc-podcast.ics above.
  2. Open this folder on your Mac: ~/Projects/abc-podcast. Drop the downloaded file in there.
  3. In Terminal, run:
    cd ~/Projects/abc-podcast && git add abc-podcast.ics && git commit -m "update calendar" && git push
  4. The feed URL will be: https://atlas-anesthesia.github.io/abc-podcast/abc-podcast.ics
  5. In Google Calendar, click + next to "Other calendars" → From URL → paste that URL.

Each time you change the schedule: re-download, replace the file, re-run the git command. Google Calendar polls roughly every 24h.

💡 For instant calendar adds on your own account, use the per-event "Add to Google Calendar" button on each scheduled call — no setup needed.
